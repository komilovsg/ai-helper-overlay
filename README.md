# 🧠 AI Helper Overlay

**AI Helper Overlay** — это кроссплатформенное Electron-приложение, которое помогает программистам на собеседованиях. Оно позволяет распознать текст с экрана (OCR), отправить его в ChatGPT и мгновенно получить ответ в оверлейном окне поверх всех окон.

---

## 🚀 Основные функции

- 📸 **Горячая клавиша:** `Ctrl + Shift + A` делает скриншот экрана.
- 🔍 **OCR:** Распознаёт текст на изображении с помощью `Tesseract.js`.
- 🤖 **ChatGPT:** Отправляет распознанный текст в OpenAI GPT-4.
- 💬 **Оверлей:** Показывает ответ от ChatGPT прямо поверх всех окон.
- ⚡ **Мгновенно:** Работа в фоне, без необходимости переключения окон.

⚙️ Зависимости

Пакет Назначение
`electron` Создание кроссплатформенных десктопных приложений
`tesseract.js` OCR — распознавание текста с изображений
`axios HTTP`-запросы к API OpenAI
`dotenv` Загрузка переменных окружения
`electron-builder` Сборка установщика для Windows

🧠 Как это работает
Пользователь нажимает `Ctrl + Shift + A`.

Приложение делает снимок экрана.

Изображение передаётся в `Tesseract.js`, и распознанный текст отправляется в `ChatGPT`.

Ответ отображается в прозрачном окне поверх всех программ.
